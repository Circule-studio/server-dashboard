Tout ton homelab sur une seule page

Server Dashboard réunit tes services, l’état de tes machines, tes conteneurs Docker et 40 widgets dans un tableau de bord léger que tu héberges toi-même. Une commande suffit pour l’installer.

Ce qu’il fait

L’essentiel d’un dashboard de homelab, sans base de données ni étape de build.

Tout au même endroit

Tuiles d’applications, onglets, favoris et recherche au clavier. Le statut est vérifié par le serveur, services locaux compris.

Tes machines d’un coup d’œil

Stats du serveur, Proxmox VE, Glances, ou un agent qui ne demande aucun port ouvert. Avec des courbes sur 24 h et 7 jours.

Des alertes, même page fermée

ntfy, Gotify, Discord ou webhook quand une application tombe, qu’une VM s’arrête ou qu’un disque se remplit.

Les mises à jour en attente

Paquets apt et images Docker, machine par machine. Le dashboard les montre, il n’installe rien.

Docker à portée de clic

L’état de tes conteneurs, avec démarrage, arrêt et redémarrage une fois connecté.

Tout se règle dans l’interface

Glisser-déposer, thème clair ou sombre, couleur d’accent, image de fond et seuils d’alerte, sans fichier à éditer.

Sur ton téléphone

L’interface s’adapte à l’écran et s’installe comme une application.

Secrets côté serveur

Tes clés API et mots de passe restent sur le serveur : ils ne sont jamais envoyés au navigateur.

Léger et lisible

Node.js avec une seule dépendance (Express) et du HTML/CSS/JS sans framework. Facile à lire et à modifier.

Installation

Sur n'importe quel serveur Linux : VPS, Raspberry Pi, conteneur LXC Proxmox, NAS…

Sans Docker, en une commande

Debian 12+ ou Ubuntu 22.04+. Installe Node.js si besoin, crée un service systemd et affiche ton mot de passe admin. Relance la même commande pour mettre à jour.

curl -fsSL https://raw.githubusercontent.com/Circule-studio/server-dashboard/main/packaging/install.sh | sudo bash

Avec Docker

Récupère la configuration

mkdir server-dashboard && cd server-dashboard
curl -fsSLO https://raw.githubusercontent.com/Circule-studio/server-dashboard/main/compose.yaml
curl -fsSL https://raw.githubusercontent.com/Circule-studio/server-dashboard/main/.env.example -o .env

Choisis ton mot de passe admin

nano .env   # remplace "change-moi"

Lance-le

docker compose up -d

Puis ouvre http://IP-DU-SERVEUR:7575 : un écran d'accueil te guide. Image prête pour amd64 et arm64 (Raspberry Pi).
