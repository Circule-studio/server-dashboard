# Code de conduite

Server Dashboard est un projet ouvert à toutes et tous, quel que soit le niveau. Pour que chacun s'y sente bien :

## Ce qu'on attend
- Rester bienveillant et patient, surtout avec les personnes qui débutent.
- Critiquer le code, jamais les personnes. Expliquer le « pourquoi » d'une remarque.
- Accepter les avis différents et chercher ce qui est le mieux pour le projet.
- Reconnaître ses erreurs et en tirer quelque chose.

## Ce qui n'est pas accepté
- Insultes, moqueries, harcèlement, propos discriminatoires.
- Publier des informations privées sur quelqu'un sans son accord.
- Spam, autopromotion hors sujet, trolling.

## Que faire en cas de problème
Contacte les mainteneurs en privé via le [signalement privé GitHub](https://github.com/Circule-studio/server-dashboard/security/advisories/new) ou par message à [@thomas370](https://github.com/thomas370). Les signalements sont traités avec discrétion.

Les mainteneurs peuvent masquer des commentaires, fermer des discussions ou exclure du projet une personne qui ne respecte pas ces règles.

Ce code s'inspire du [Contributor Covenant](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).
